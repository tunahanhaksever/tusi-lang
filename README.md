# 🇹🇷 Tusi Programlama Dili (v3.0 - On Numara)

### Türkiye'nin Yerli ve Milli Programlama Dili
**Tusi**, Türkçenin sondan eklemeli, matematiksel ve algoritmik dehasını modern bilişim dünyasıyla buluşturan profesyonel bir programlama dili motorudur. Amerikan analitik düşünce yapısına karşı, Anadolu'nun zihinsel kodlarını dijital dünyada bir "İhtilal"e dönüştürmek için tasarlanmıştır.

---

## 🌟 Neden Tusi?

*   **Sözde Değil, Özde Türkçe:** Sadece anahtar kelimeler değil, Türkçenin **sondan eklemeli zekası** koda entegre edilmiştir. `eğerse`, `eğersa`, `yaparsa` gibi ekler otomatik olarak çözümlenir.
*   **Tam Donanımlı (Full-Stack):** Dahili veritabanı motoru, web framework altyapısı ve dış sistemlerle (Python, Node.js, CMD) tam uyum.
*   **Hız ve Güç:** Dünyanın en hızlı motorlarından biri olan V8 (Node.js) üzerinde yükselir.
*   **Milli Güvenlik (Anti-Hack):** İleri seviye "Path Isolation" teknolojisiyle donatılmış, siber saldırılara karşı dirençli bir çekirdeğe sahiptir.

### Örnek "On Numara" Kod

```tusi
// Tusi ile Veritabanı ve Karar Yapısı
değişken kullanıcılar = vt_oku("kullanıcılar")

eğerse (uzunluk(kullanıcılar) > 0) ise {
    yazdır("Sistemde " + uzunluk(kullanıcılar) + " kullanıcı mevcut.")
} değilse {
    yazdır("Henüz kimse kayıt olmamış.")
}
```
