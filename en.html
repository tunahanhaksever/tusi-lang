📦 TPM — Tusi Package Manager

TPM is the official package distribution tool for Tusi, enabling developers to install modular libraries with a single terminal command.

📥 Command Line Installation:

tpm kur muhasebe-pro tpm kur tusi-gui-plus tpm kur yapay-zeka-tusi tpm listele

📚 Official Package Registry:

  • muhasebe-pro: Advanced commercial invoicing, tax calculation, and profit/loss balance sheets.
  • tusi-gui-plus: Desktop visual windows, interactive tables, input controls, and buttons.
  • excel-veri: High-performance Excel and CSV data reading, filtering, and aggregation.
  • yapay-zeka-tusi: Natural language processing and algorithmic text generation engine.
  • tusi-sql: In-memory relational database query engine.
